# Tweaks for Sailfish OS for the Xperia 10 V

This repository contains tweaks for using the Xperia 10 V with Sailfish OS. All tweaks are based on the official Jolla port. If you want to use the LineageOS-based community port, see [this forum thread](https://forum.sailfishos.org/t/lineage-based-port-for-xperia-10-v-zambezi/31348).

## Camera

The camera does not work on the stock Jolla port because of problems with the AOSP kernel and the binaries provided by Sony. [This guide](camera/guide.md) describes how to get the cameras working.
